# Phone Trigger assets

Place **`divmeter.mp4`** in this folder (divergence meter clip).

When you send mail to **PhoneWave (name subject to change)**, Phone Trigger plays this video fullscreen, then applies a short screen distortion so the cut back to chat is less abrupt. If the file is missing, a CSS divergence-meter fallback runs instead.

Expected path after install:

`scripts/extensions/third-party/Penumbra-Phantasm/assets/divmeter.mp4`
