# Phone Trigger assets

Divergence meter clip used for D-Mail:

- **Primary:** `lib/vid/divmeter.mp4`
- **Fallback path:** `assets/divmeter.mp4` (optional copy)

When you send mail to **PhoneWave (name subject to change)**, Phone Trigger plays this video fullscreen, then applies a short screen distortion so the cut back to chat is less abrupt. If neither file loads, a CSS divergence-meter fallback runs instead.
